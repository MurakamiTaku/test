# 日本株 投資シミュレーション

架空の日本株指数（幾何ブラウン運動で生成）を使って、投資戦略を比べる教育用シミュレーションです。
Python 3 の標準ライブラリだけで動きます。

```bash
python3 simulation.py                       # デフォルト: 20年・毎月3万円
python3 simulation.py --years 30 --monthly 50000 --vol 0.22 --seed 7
python3 simulation.py --help
```

## 内容
- **戦略比較**: 一括投資 / 毎月積立 / 12か月移動平均トレンドフォロー（課税口座とNISAの両方）
- **モンテカルロ**: 積立投資を数千通りの未来で試し、最終資産の分布と元本割れ確率を表示
- **期間別の元本割れ確率**: 長く続けるほどリスクがどう変わるか

## 注意
- 株価は乱数で作った架空データです。実際の日経平均・TOPIXではありません。
- 期待リターン・変動率などの前提を変えると結果は大きく変わります。
- 投資判断の助言ではありません。

## スマホ・ブラウザ版
`index.html` をブラウザで開くだけで動きます（インストール不要）。
スライダーで積立額・期間・利回り・値動きの大きさ・NISA の有無を変えると、2,000 通りの未来で再計算します。
GitHub Pages を有効にすれば、スマホから URL で開けます。
